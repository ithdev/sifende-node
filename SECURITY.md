# Seguridad

Para que una vulnerabilidad no quede expuesta antes de corregirla, reportala en privado, no en un issue público.

Usá **Report a vulnerability** en la pestaña [Security](https://github.com/ithdev/sifende-node/security) del repo.
Incluí la versión del SDK, los pasos para reproducirla y el impacto que ves.

Solo la última versión publicada de `@sifende/sdk` recibe correcciones de seguridad.

Si la vulnerabilidad está en la API de Sifende y no en el SDK, reportala por el mismo canal.
